# Project 02 — Data Visualization with Matplotlib & Seaborn

## Project Overview
This project explores restaurant data using Python visualization libraries.

## Dataset
Seaborn Tips Dataset (`tips.csv`).

## Visualizations
1. Histogram — Distribution of total bills.
2. Box Plot — Tip distribution across different days.
3. Scatter Plot — Relationship between total bills and tips.
4. Correlation Heatmap — Relationships between numerical variables.

## Technologies Used
- Python
- Pandas
- Matplotlib
- Seaborn
- Jupyter Notebook

## Project Files
- `project_02_visualization.ipynb`
- `project_02_visualization.py`
- `tips.csv`
- `tips_visualization_dashboard.png`
- `submission_notes.md`

## How to Run
Install dependencies:

```bash
pip install pandas numpy matplotlib seaborn jupyter
```

Open the Jupyter Notebook and run all cells.

## Outcome
A four-chart dashboard with observations and insights from the dataset.
